    ### Conventions (apply to all later tickets)

    - Document coordinates: points, origin top-left, y grows downward. Renderers set up the CGContext so drawing code uses these coordinates directly.
    - Model types are value types, `Equatable`, `Sendable`; annotation types are also `Codable` (needed later for copy/paste between windows).

    ### Code (`Sources/YSkitchCore/`)

    - `RGBAColor`: sRGB components `red, green, blue, alpha: Double` (0...1); `cgColor` (sRGB); `init(hex: UInt32, alpha:)` convenience. `Codable`, `Equatable`, `Hashable`, `Sendable`.
    - `BaseImage`: `cgImage: CGImage`, `scale: CGFloat` (pixels per point, ≥ 1); computed `pixelSize: CGSize`, `pointSize: CGSize`. `Sendable` (use `@unchecked Sendable` only if CGImage isn't Sendable in this SDK; CGImage is immutable). `Equatable` by identity of `cgImage` (`===`) and scale.
    - `Annotation`: `struct`, `Identifiable` (`id: UUID`), `Codable`, `Equatable`, `Sendable`. Fields: `id`, `style: AnnotationStyle`, `shape: AnnotationShape`.
    - `AnnotationStyle`: `color: RGBAColor`, `thickness: CGFloat` (points).
    - `AnnotationShape`: `enum`, `Codable`, `Equatable`, `Sendable`. For now one case: `rectangle(CGRect)`. Later tickets add cases.
    - `Document`: `struct`, `Equatable`, `Sendable`.
      - `base: BaseImage?` (nil = blank canvas)
      - `imageRect: CGRect` — points; origin `.zero`; size = `base.pointSize`, or the blank size.
      - `scale: CGFloat` — output pixels per point (`base.scale`, or given for blank).
      - `annotations: [Annotation]` — drawing order (last on top).
      - `canvasRect: CGRect` (computed) — for now equals `imageRect`. A later ticket extends it with annotation bounds.
      - Initializers: `init(image: BaseImage)`, `init(blankSize: CGSize, scale: CGFloat)`.
    - `Renderer` (`enum`, static funcs):
      - `draw(_ document: Document, in context: CGContext)` — context is already in document coordinates (y-down). Fills `canvasRect` white, draws the base image upright into `imageRect` (account for the y-down flip so the image is not upside down), then annotations in order via `AnnotationRenderer`.
      - `flatten(_ document: Document) -> CGImage` — bitmap of `ceil(canvasRect.size × scale)` pixels, 8 bits/component, sRGB, **no alpha** (`CGImageAlphaInfo.noneSkipLast`), so output is always opaque. Sets up the transform (scale, flip to y-down, translate by `-canvasRect.origin`), then calls `draw`. Interpolation `.high`.
    - `AnnotationRenderer.draw(_ annotation: Annotation, in context: CGContext)` — `switch` on shape; `rectangle`: plain stroke with style color and thickness (outline styling comes later), line join miter.

    - `enum OutlineStyle` — named constants and helpers:
      - `haloBlur: CGFloat = 2` (points), `haloColor` = black at alpha 0.5, `whiteRatio: CGFloat = 0.25`, `whiteMinimum: CGFloat = 1` (points).
      - `whiteWidth(forLineWidth:) -> CGFloat` = `max(whiteMinimum, lineWidth * whiteRatio)`.
      - `extent(outlineWidth:) -> CGFloat` = `outlineWidth + haloBlur * 2` — how far beyond the shape's own edge the rendering reaches (used later for canvas bounds and redraw rects).
    - `enum OutlinedDrawing`:
      - `stroke(_ path: CGPath, lineWidth: CGFloat, color: CGColor, lineCap: CGLineCap, lineJoin: CGLineJoin, in context: CGContext)`.
      - `fill(_ path: CGPath, color: CGColor, outlineWidth: CGFloat, in context: CGContext)` — for filled shapes such as arrows and text glyph outlines.
      - Rendering, both functions:
        1. `saveGState`; `setShadow(offset: .zero, blur: haloBlur × deviceScale, color: haloColor)` where `deviceScale = hypot(ctm.a, ctm.b)` of `context.userSpaceToDeviceSpaceTransform` (shadow blur is in device space, not user space — without this the halo is half as wide at 2×).
        2. `beginTransparencyLayer(auxiliaryInfo: nil)` so the shadow applies once to the combined white shape.
        3. Draw the white outline shape: for `stroke`, stroke the path with `lineWidth + 2 × white` in white (same cap/join); for `fill`, fill the path in white and stroke it with `2 × outlineWidth` (round join).
        4. `endTransparencyLayer`; `restoreGState`.
        5. Draw the object itself without shadow: stroke with `lineWidth` / fill with `color`.
    - `AnnotationRenderer`: `.rectangle` now uses `OutlinedDrawing.stroke` (miter join, butt cap).

    ### Tests (`Tests/YSkitchCoreTests/OutlinedDrawingTests.swift`)

  * ## Ticket: Task: Canvas view - zoom, pan, HiDPI {#6}

        status: done
        created: 2026-11-23 14:20:46 UTC
        updated: 2026-11-23 14:58:16 UTC

    Requirements: VIEW-1, VIEW-2, VIEW-3, §6 canvas surround color.

    ### Approach

    Use `NSScrollView` magnification: it gives native pinch zoom around the gesture point and two-finger panning for free. Magnification 1.0 = 100% = "actual size": 1 document point per screen point, so a 2× image on a Retina screen shows 1 image pixel per device pixel.

    ### Core (`Sources/YSkitchCore/Zoom.swift`) — pure logic, tested

    - `enum Zoom`:
      - `static let steps: [CGFloat] = [0.05, 0.1, 0.125, 0.25, 0.333, 0.5, 0.667, 0.75, 1, 1.5, 2, 3, 4, 6, 8, 12, 16, 24, 32]`; `minimum = steps.first`, `maximum = steps.last`.
      - `static func stepUp(from: CGFloat) -> CGFloat` / `stepDown(from:)` — next step strictly above/below (tolerance 0.001); clamped to min/max.
      - `static func fit(content: CGSize, viewport: CGSize) -> CGFloat` — `min(viewport.w / content.w, viewport.h / content.h, 1)`, clamped to `minimum`. Never enlarges beyond 100%.
      - `static func wheel(magnification: CGFloat, deltaY: CGFloat) -> CGFloat` — `magnification * exp(deltaY * 0.01)`, clamped.

    ### UI (`Sources/YSkitchUI/Canvas/`)

    - `CanvasStyle.surroundColor` (`@MainActor enum CanvasStyle`) — neutral grey `NSColor(srgbRed: 0.45, green: 0.45, blue: 0.45, alpha: 1)`. Update `docs/requirements.md` §6 to name it `CanvasStyle.surroundColor` instead of `CanvasSurroundColor`.
    - `DocumentModel` (`@MainActor final class`): holds `var document: Document`; `onChange: (() -> Void)?` callback invoked from `didSet`. Undo comes in a later ticket — keep mutations going through this object.
    - `CanvasView: NSView` — the scroll view's document view.
      - `isFlipped = true` (y-down, matching document coordinates). Frame size = `document.canvasRect.size`. In `draw(_:)`: get `NSGraphicsContext.current!.cgContext`, translate by `-canvasRect.origin`, call `Renderer.draw(document, in:)`.
      - Image interpolation: if the effective device pixels per image pixel ≥ 2 (magnification × window backing scale / document scale ≥ 2), use `.none` (crisp pixels when zoomed in); otherwise `.high`.
      - `wantsLayer = true`, layer shadow for a subtle page shadow is optional — skip unless trivial.
      - Space+drag panning: on `keyDown` with keyCode 49 (space, not repeat) enter pan mode (open-hand cursor); `keyUp` exits. While in pan mode, `mouseDown`/`mouseDragged` scroll the clip view by the drag delta (closed-hand cursor). Accepts first responder. Later tools will use mouse events when not panning, so keep the pan logic isolated (small helper or clearly separated methods).
    - `CenteringClipView: NSClipView` — override `constrainBoundsRect(_:)` so a document smaller than the viewport is centered (per axis) instead of pinned to the corner.
    - `CanvasScrollView: NSScrollView`:
      - `allowsMagnification = true`, `minMagnification = Zoom.minimum`, `maxMagnification = Zoom.maximum`, scrollers on and auto-hiding, `backgroundColor = CanvasStyle.surroundColor`, `drawsBackground = true`, content view = `CenteringClipView`.
      - `smartMagnify(with:)` override (two-finger double-tap): toggle between Fit and 100% (if current ≈ 1 → fit, else → 1), centered on the gesture location.
      - `scrollWheel(with:)` override: with `⌘` held → `setMagnification(Zoom.wheel(...), centeredAt:)` at the mouse location (document view coordinates); otherwise `super`.
      - `zoomIn()`, `zoomOut()` (via `Zoom.stepUp/Down`, centered on the visible center), `zoomToActualSize()` (1.0, keep visible center), `zoomToFit()` (`Zoom.fit` using `contentView.bounds.size` at magnification 1 — i.e. the clip view's frame size — then center).
      - `onMagnificationChange: ((CGFloat) -> Void)?` — called whenever magnification changes, including live pinch. Use KVO on `magnification` (`observe(\.magnification)`). The status bar ticket will use it.
      - Request a canvas redraw when magnification changes (interpolation choice depends on it).
    - `DocumentWindowController`:
      - `init(document: Document)`; default for `⌘N` for now: `Document(blankSize: 1024×768, scale: window backing scale or NSScreen.main scale, default 2)`.
      - Content view = `CanvasScrollView` with `CanvasView` as document view. Initial zoom: fit.
      - Actions (`@objc`, reachable via responder chain): `zoomIn(_:)`, `zoomOut(_:)`, `zoomToActualSize(_:)`, `zoomToFit(_:)`.
    - `MainMenu` View menu, above "Enter Full Screen" + separator: Zoom In `⌘+` (keyEquivalent "+") plus a hidden alternate item with keyEquivalent "=" (`isHidden = true`, `allowsKeyEquivalentWhenHidden = true`) so `⌘=` works without Shift; Zoom Out `⌘-`; Actual Size `⌘0`; Zoom to Fit `⌘9`.

    ### Tests

    - Core `ZoomTests`: step up/down incl. between-steps and clamping; fit for larger/smaller content (never > 1); wheel clamping.
    - UI: `CenteringClipView` centers a small document (bounds origin negative by half the slack) and doesn't center a large one; `DocumentWindowController` with a 2000×1000 pt document → canvas view frame size 2000×1000; after `zoomToActualSize` magnification == 1; menu has Zoom In/Out/Actual Size/Zoom to Fit with the right key equivalents.

    ### Acceptance

    - `./test.sh`, `./build.sh` pass; no warnings from our sources.
    - App launch shows a white 1024×768 canvas centered on grey, fit to window.

    Requirements: ED-6.

    ### Design

    Document snapshots: `Document` is a value type (base image shared by reference), so each undo step stores the previous `Document` value. Unlimited levels, per window.

    ### UI (`Sources/YSkitchUI/DocumentModel.swift`)

    - `DocumentModel` owns `let undoManager = UndoManager()`.
    - `document` becomes `private(set)`; all mutations go through:
      - `perform(_ actionName: String, _ change: (inout Document) -> Void)` — applies the change; if the document actually changed (`!=`), registers one undo step named `actionName`.
      - Gesture API for live edits (dragging a shape, moving a selection), coalesced into one undo step:
        - `beginGesture()` — remembers the current document as the gesture's start snapshot (nested calls are a programming error: `precondition`).
        - `updateGesture(_ change: (inout Document) -> Void)` — mutates without registering undo.
        - `endGesture(_ actionName: String)` — registers one undo step from the start snapshot if the document changed; clears the snapshot.
        - `cancelGesture()` — restores the start snapshot without registering undo.
        - `isInGesture: Bool`.
      - Undo/redo: register with `undoManager.registerUndo(withTarget: self) { $0.restore(previous, actionName:) }`, where `restore` sets the document and registers the inverse (so redo works), and `setActionName`.
    - `onChange` still fires on every document change (including undo/redo and gesture updates).
    - `DocumentWindowController` is the window's delegate (or sets it) and implements `windowWillReturnUndoManager(_:)` → `model.undoManager`, so the Edit menu's `undo:`/`redo:` (already present, nil target) work through the window, with titles like "Undo Draw Rectangle" provided by AppKit's menu validation.
    - Update existing call sites that assign `model.document` directly to use `perform` (or an internal non-undoable setter if one is needed for loading — prefer none).

    ### Tests (`Tests/YSkitchUITests/UndoTests.swift`)

    Use a `.rectangle` annotation as the mutation.
    - `perform` → `undoManager.canUndo`, `undoActionName == "Draw Rectangle"`; undo restores; redo reapplies.
    - No-op `perform` (no change) registers nothing.
    - Gesture: begin, three updates, end → exactly one undo step; undo returns to the pre-gesture document.

    - Several steps undo in reverse order; `onChange` fires on undo/redo.
